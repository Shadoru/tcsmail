# Contribuindo

Obrigado por ajudar no TCS Mail.

## Antes de abrir uma issue

- Use a versão mais recente da [release pública](https://github.com/Shadoru/tcsmail/releases/latest).
- Informe sistema operacional, arquitetura, formato instalado e versão.
- Não envie senhas, tokens, conteúdo de e-mails, anexos ou dados pessoais.
- Para problemas de segurança, siga SECURITY.md e não abra uma issue pública.

## Bugs e melhorias

Abra uma issue com passos mínimos para reproduzir, comportamento esperado, comportamento observado e evidências sem dados sensíveis.

Pull requests devem explicar o motivo da alteração e incluir os testes executados. Os workflows de compilação e publicação são manuais; uma contribuição não deve introduzir publicação automática de releases.
