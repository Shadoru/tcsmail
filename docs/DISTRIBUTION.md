# Distribuição oficial

## Fonte de verdade

- Site: https://thecreativesolver.com/tcsmail/
- Repositório: https://github.com/Shadoru/tcsmail
- Downloads: https://github.com/Shadoru/tcsmail/releases/latest
- Release atual: [TCS Mail 0.8.3 r15](https://github.com/Shadoru/tcsmail/releases/tag/installers-0.8.3-r15)

A versão do aplicativo é **0.8.3**. r15 identifica a revisão dos instaladores e não uma nova versão do aplicativo.

## Formatos publicados

| Sistema | Arquivos |
|---|---|
| Linux x86_64 | DEB, RPM, AppImage |
| Windows x86_64 | EXE, MSI |
| macOS Apple Silicon | DMG, APP.zip |
| macOS Intel | DMG, APP.zip |

O site pode apresentar seleção automática por sistema, mas o GitHub permanece como origem dos binários.

## Integridade

Use [o manifesto SHA-256](RELEASES-0.8.3-R15-SHA256SUMS.txt) para conferir os hashes publicados pelo GitHub.
