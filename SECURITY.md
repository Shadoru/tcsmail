# Segurança

Não publique credenciais, tokens OAuth, senhas, chaves privadas, conteúdo de mensagens ou anexos em issues, logs, screenshots ou pull requests.

Para relatar uma vulnerabilidade, contate **tcsmail@thecreativesolver.com** com uma descrição reproduzível e a versão afetada. Não use uma issue pública para dados sensíveis.

As releases oficiais são publicadas em:
https://github.com/Shadoru/tcsmail/releases

A chave GPG pública, quando usada para verificar uma release, está em .github/keys/tcs-mail-release-public.asc. A ausência de assinatura nativa de Windows ou macOS não deve ser interpretada como assinatura existente.
